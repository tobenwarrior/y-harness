# Compound for Empryo

Read the [bundled Compound guidance](../../../packages/skill/skill-compound/assets/compound/SKILL.md) and workflows in `packages/skill/skill-compound/assets/compound/references/`. Apply this adapter instead of the upstream startup scan and host activation steps. It is specific to Empryo; it does not install or activate Compound in other hosts.

For repository orientation, use Empryo's Genome, search, and navigation tools instead of running Compound's startup code-map scan. The Genome is bounded: confirm behavior, callers, and omissions in source and tests. For a visual map request, prefer Empryo's native map when available. If it is unavailable or the user requests the Compound viewer, follow [code maps](../../../packages/skill/skill-compound/assets/compound/references/map.md); do not start the viewer for routine orientation.

Read the relevant workflow before the work: [investigate](../../../packages/skill/skill-compound/assets/compound/references/investigate.md), [design](../../../packages/skill/skill-compound/assets/compound/references/design.md), [debug](../../../packages/skill/skill-compound/assets/compound/references/debug.md), [refactor](../../../packages/skill/skill-compound/assets/compound/references/refactor.md), [performance](../../../packages/skill/skill-compound/assets/compound/references/performance.md), [review](../../../packages/skill/skill-compound/assets/compound/references/review.md), or [repository hygiene](../../../packages/skill/skill-compound/assets/compound/references/repo-hygiene.md). Read [verification](../../../packages/skill/skill-compound/assets/compound/references/verify.md) before reporting completion and [Git](../../../packages/skill/skill-compound/assets/compound/references/git.md) before an authorized commit or push.

Follow the repository's `AGENTS.md`, user instructions, and the host's safety rules. Do not run Compound's setup or onboarding cleanup, install software, or change settings merely because this skill is active.
