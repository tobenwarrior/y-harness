# @deepseek-ai/dsh-client-ui-skill-library

[English](README.md) | 中文

## 概述

按项目或共享范围浏览技能，查看指令及修订历史，并探索明确关联。在应用完整的更改提案前，审阅已记录的证据和不确定性。通过经过审阅且可恢复的操作接管和维护符合条件的技能。将面板与 Host 技能库一起使用；原生及受保护来源保持只读。

## 使用此包

将此浏览器插件与 `dsh-skill-library` 和 API Remotes 一起加载。从侧边栏打开 Skills（技能），在文档或图谱旁浏览一个紧凑的 Project（项目）和 Shared（共享）文件列表。浏览器应用侧边栏可以收起为已有的图标栏；macOS Desktop 保留应用原有的隐藏侧边栏行为与重新打开控件。技能文件列表在两个视图中都可用，也可以单独隐藏。模式页签与搜索和筛选控件使用两行紧凑布局，状态区显示技能数量与来源可用性。搜索与状态筛选只使用元信息；选择技能时才读取指令和修订历史。关系图显示全部匹配技能，支持项目筛选、平移、缩放、适应画布和键盘操作。图谱控件浮在画布上，详情面板可以收起，同时保留所选技能与已读取的指令。稳定的项目颜色标识归属，技能节点大小反映明确链接的度数，分组节点保持不同外观。放大时逐步显示名称；所选、悬停与获得键盘焦点的名称始终可见。图谱区分项目归属和已解析的明确链接，不推断相似性或使用情况。

固定技能可以保护维护操作。加入 Y 管理是单独的明确操作，不会同时启用自动精简或语义学习。**删除**会从发现范围移除符合条件的来源，并在 Host 归档中保留完整资源包；**已删除技能**筛选这些条目，其详情提供**恢复**。受管理技能还提供经过审阅的空白精简及历史指令恢复。**精简此技能**要求针对当前版本的按文件同意及已批准的压缩或归档策略。**强制精简**立即请求检查，仍核对维护权限、固定状态、策略及来源哈希。已有用户技能和提供方技能保留 Host 定义的保护。原生来源仅提供元信息时，指令大小和使用情况显示未知；不可用提供方保持可见。不提供永久删除。

### 审核语义提案

Review（审核）页签列出按项目划分的创建、更新、压缩和可恢复归档提案。符合条件且有实质内容的已完成工作可以建议创建或更新提案；维护检查生成压缩与重复技能归档提案。选择提案时读取完整的前后差异、已记录的任务证据、不确定性及任何验证结论。完成状态和工具结果不能证明技能使用成功；审核区分观察记录与独立检查。原生工作观察记录保持未验证。

归档审核还会在源内容移除差异旁展示完整的保留技能快照，包括其标识、来源与资源哈希、指令、资源和关联。应用归档前，Host 会检查整个资源包是否等效，并保留已解析的引用目标；仅链接文字相同不能证明等效。

审核详情后明确应用或拒绝提案。自动应用还要求已批准的策略及针对完整提案的受信任验证回执；已有来源必须具有针对当前版本的同意。应用更改前，Host 检查当前来源哈希和保护状态；固定、受保护和原生来源技能仍不能接受语义维护。已应用的指令更改保留修订历史以供回滚，归档的资源包可以恢复。处于应用中状态的中断提案提供**继续应用**；Host 会核对已提交的修改，并在继续前重新检查所有剩余来源与维护权限。

### 学习范围

批准已有技能的策略，再单独启用**自动学习**，以授权维护其当前版本。撤销策略或关闭按文件同意会停止该授权。空白精简具有单独的启用设置。

从工具栏打开**项目学习**，即可在尚无技能时授权新建。选择已知项目，明确允许根据原生工作新建技能，再批准项目策略。这允许根据有实质内容的记录另外创建由 Y 管理的技能；已有受保护来源仍需明确加入管理，记录中的结果保持未验证。即使原生学习提供方不可用，弹窗仍提供项目策略撤销。

### Decision 设置

设置 → 模型包含独立的 Decision 页尾。选择可用的仅返回响应的 API 模型，明确选择提供方声明的推理强度和处理档位，再根据当前配置保存启用状态。原生 Codex 路由明确显示不可用。聊天模型和权限保持不变。选择已注册项目及查询，明确预览候选顺序；普通技能或模型页面浏览不进行建议调用。结果保留确定性候选成员和明确选择，失败时使用确定性顺序。Host 负责请求、token、超时及日志限制，预览会说明这些限制，但不能证明模型质量。

<a id="understand-the-implementation"></a>
## 理解实现

`controller.ts` 拥有 Remote 查询和操作状态，刷新失败保留元信息，忽略切换选择后返回的旧详情，并在编辑请求中发送已观察到的内容哈希。`navigation-store.ts` 只保存视图状态。`SkillLibraryPage.tsx` 使用框架 hooks 和回调；`SkillGraph.tsx` 只使用元信息，不读取指令。确定性的关系图布局使用明确链接与项目归属锚点，执行固定的 36 轮计算与有界近邻采样。它没有持续求解器、图数据库或第三方关系图依赖。手动刷新请求新的原生元信息；普通读取不会启动原生运行时。[Host 技能库](../../skill/skill-library/README.zh.md) 负责证据采集、已注册的提案生成器、验证与同意检查、自动维护及文件历史。

<a id="model-experience"></a>
## Model Experience

### 技能库审核与维护

#### 模型看到的内容

`SkillLibraryPage` 的浏览和审核操作不会更改请求消息或工具 schema。提案生成通过已注册的 Host 生成器执行，该生成器可能使用选定证据和技能指令调用模型。维护通过 Host 更新技能文件；随后加载技能时可以向模型提供更新后的指令。关系图仍用于人工导航。

#### Token 影响

浏览已有提案、证据和差异不增加模型 token。此包本身不进行模型调用；生成提案的模型成本由已注册的 Host 生成器负责。编辑后的技能随后加载时，其 token 成本由 Host 技能加载器负责。

#### KV Cache 影响

界面不编辑提示词或历史记录。生成请求及其缓存行为由 Host 生成器负责。之后加载技能沿用 Host 加载器现有的请求准入与日志行为。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **证据范围** — 加载记录和已完成任务不代表技能成功应用。未知使用记录不会被标为未使用或很少使用。此界面不会为原生隐式加载或不可用的指令正文自动补充学习覆盖。
- **语义提供方** — 此包不提供生成器或验证器。审核展示 Host 记录的证据及已注册的验证结果，不能仅凭任务完成、模型声明或正文变短证明语义正确。Host 验证器只授权其记录的范围；原生观察学习不代表结果已验证。
- **维护范围** — 空白精简只移除代码块之外的多余空行。自动维护要求已批准的策略、验证及针对当前版本的同意；强制精简不会扩大这些权限。提供方技能保持只读。关系图使用明确关联，删除保留可恢复的资源包。
