# Y Harness Brand Guidelines

Use **Y Harness** as the project name in documentation, application copy, package descriptions, and community discussions.

- Describe Y Harness as an independent project. Do not imply endorsement, sponsorship, or official affiliation with a model provider or upstream project.
- Use provider names only when they identify an actual integration or model service. For example, DeepSeek may appear as a provider name in model configuration and provider documentation.
- Use the project-owned Y Harness logo and assets when presenting the project. Do not reuse another project's brand assets in a way that could mislead users.
- Keep license, copyright, and upstream-source notices intact in their owning legal or attribution files.
