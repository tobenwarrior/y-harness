# 先选择提供方，再选择其模型

[English](guide.md) | 中文

## 变更

Composer 将原来的 Provider 信息行与分组 Model 列表改为可操作的 Provider 行，随后只显示该路由的 Model 列表。未选模型时先打开提供方列表。仅当所选提供方超过四个模型时显示模型搜索。`/model` 命令保留按提供方分组的可搜索目录。

浏览提供方只是临时选择，直到用户明确选定模型才保存。关闭菜单恢复已保存路由。显式选择且兼容的推理强度与速度随新模型保留；不支持的值使用目标模型默认值。既有提供方与模型选择继续加载。

## 迁移

1. 打开 composer 模型控件，选择 Provider，再选择所需路由。菜单只打开该提供方的模型。
2. 选择模型以保存完整的提供方与模型选择。检查已选模型显示的推理强度与速度。Escape 离开模型列表，再次按 Escape 关闭菜单而不接受草稿。
3. 需要搜索所有提供方时使用 `/model`。确认 composer 显示已选模型，且 Provider 行标识目标路由。无需迁移资料文件或凭据。
