# 托管 Markdown skill（技能）加载

[English](README.md) | 中文

这个人工编写、无需密钥的已录制会话启动随产品发布的 headless profile，通过公开的 Skill Library 服务接管一个过大的目录 skill，应用已审阅的拆分结果，再通过普通 `skill` 工具加载选定的生成入口。随后，它只用普通 `read` 工具读取链接的 Setup 主题。提交到仓库的会话检查模型可见的准确入口和选定主题；`workspace.expected/world.json` 独立保留全部八个来源片段、主题、入口回执和 manifest（元数据清单）文件的准确字节与哈希。此场景将这份固定记录还原到自有临时目录树中，交给未改动的完整工作区比较器；运行时文件缺失、多出或改变仍会失败。JSON 转义保留生成的空行，不放宽仓库的空白检查。fixture（测试前置数据）插件断言保留的片段能逐字节重建原始来源，只加载根入口的请求不包含任何来源细节，最终请求包含选定主题的每一行，且未选定的 Review 细节始终不出现。

回放使用仓库的快照运行器，并传入 `-t managed-markdown-skill-load`。源码模式要求 Skill Library 已接入 Markdown 拆分；产物模式还要求先执行常规仓库构建。此人工编写的回放不使用实时模型。
